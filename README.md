# Heart-Disease-Risk-Prediction

## Project Overview
This repository contains a machine learning project that builds a Decision Tree classification model to predict the risk of heart disease. Utilizing clinical and demographic data, this project emphasizes both predictive accuracy and the interpretability of key medical factors contributing to heart disease risk.

## Objectives
* **Data Cleaning & Preprocessing: Handle missing values, encode categorical variables, and normalize numerical features to prepare the clinical dataset.
* **Exploratory Data Analysis (EDA): Identify trends, correlations, and distributions of key medical indicators (e.g., cholesterol, max heart rate, blood pressure).
* **Model Development: Train and tune a Decision Tree Classifier to predict heart disease presence.
* **Interpretability: Extract and visualize feature importance and the decision tree structure to understand *how* the model makes its medical predictions.

## Technologies & Tools
* **Programming Language: Python
* **Data Manipulation & Cleaning: NumPy, Pandas
* **Machine Learning: Scikit-learn
* **Data Visualization: Matplotlib, Seaborn, Graphviz (for tree visualization)
